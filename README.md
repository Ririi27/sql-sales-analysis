# E-commerce Sales Analysis with SQL

SQL analysis of an online-store database (500 customers, 60 products, 4,000 orders over 2024–2025) using **SQLite + Python**.

> **Data is synthetic** – generated by `sales_analysis.py` with a fixed random seed so everything is reproducible. The focus is the SQL, not real-world findings.

## SQL techniques used
Multi-table JOINs · GROUP BY / aggregates · CTEs · window functions (`RANK`, `LAG`, running `SUM`, `NTILE`) · subqueries

## Questions answered (see `queries.sql`)
- Revenue and order count by category → Electronics leads (~₹10.3M of ~₹25.1M total)
- Month-over-month growth and running total
- Top 3 products per category
- Customer segmentation by spend quartile → top 25% of customers generate **39.1%** of revenue
- Revenue by city

## Run it
```bash
pip install -r requirements.txt
python sales_analysis.py
```
Creates `sales.db`, one CSV per query and `sales_overview.png`.

**Tech:** SQL (SQLite), Python, Pandas, Matplotlib
